# DeepSeek 用量查询插件 (astrbot_plugin_deepseek_usage)

一个基于 AstrBot 的轻量级插件，允许管理员通过指令查询 DeepSeek 账户的历史 Token 使用量。

> **声明**：本插件核心代码由 DeepSeek AI 辅助生成，经人工调试与整理，仅供学习交流使用。

## ✨ 功能

- 📈 **精准用量统计**：统计总 Token（输入/输出）、请求次数。
- ⏱️ **智能分段查询**：突破官方单次查询限制，自动分段累加历史总用量。
- 🛡️ **跨年与防呆**：支持 `xx.xx` 或 `xx-xx` 格式，自动识别跨年（如 12.01 - 01.31），防呆拦截不规范输入。
- 🔐 **仅限管理员**：指令仅限 AstrBot 管理员使用，避免用量信息泄露。
- ⚡ **查询保护**：跨度超过 90 天时自动发送提示，异步请求附加休眠防封。

## ⚠️ 注意事项（必读）

1. **非官方公开接口**：本插件通过模拟浏览器行为调用 `platform.deepseek.com` 的内部私有接口（非官方公开 API）。官方随时可能修改接口结构或增加风控策略（如 Cloudflare 验证码），届时插件可能失效，需等待作者更新。
2. **封号与风控风险**：请勿将本插件用于高频、自动化的定时查询（例如每分钟查一次）。过度滥用极易触发 DeepSeek 的账号风控，**因使用不当导致的 API Key 被限流、网页账号被限制登录或封禁，需由使用者自行承担全部后果**。
3. **数据隐私与安全**：插件仅在本地向 DeepSeek 官方服务器发起请求。您的 `userToken` 仅保存在本地 AstrBot 配置文件中（已标记为 `secret` 隐藏），**绝不会**被发送至任何第三方服务器。请勿将自己的 `userToken` 截图发到公开群聊中。
4. **数据统计范围**：本插件统计的是**通过 API 接口（API Key）产生的消耗**，**不包含**您在 DeepSeek 官方网页版（`chat.deepseek.com`）进行免费对话所消耗的额度。此外，平台数据可能有几分钟的延迟，无法做到绝对实时。
5. **分段查询的耗时**：受限于官方单次查询最多 31 天的限制，当您查询跨度超过 90 天时，插件会在后台自动分段（每 30 天一段）进行累加请求。此时机器人可能需要等待 5~15 秒才能返回结果，请耐心等待，不要重复发送指令。
6. **跨年查询的局限性**：插件支持智能识别跨年日期（如输入 `12.01 01.31` 会自动识别为去年到今年）。但如果您需要查询跨越多个年份的数据，请尽量缩小单次查询范围。
7. **网络环境要求**：运行 AstrBot 的服务器必须能够正常访问 `api.deepseek.com` 与 `platform.deepseek.com`。若服务器处于严格的网络限制环境中，可能无法获取数据。
8. **模型名称展示**：数据中展示的模型列表（如 `deepseek-chat`, `deepseek-reasoner`）为平台底层记录的代号，可能与网页端显示的最新版本名称存在细微差异，但不影响 Token 总量的准确性。

## 📦 安装

1. 将本插件放入 `data/plugins/` 目录。
2. 在 WebUI 中重载插件。

## ⚙️ 配置选项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `deepseek_user_token` | string | `""` | DeepSeek 网页端 userToken（必填） |
| `default_days` | int | `30` | 默认查询天数（1/7/15/30） |
| `number_format` | string | `comma` | 数字展示格式（comma / short） |
| `request_timeout` | int | `10` | 请求超时时间（秒） |

### 如何获取 userToken（两种方法任选其一）

**方法一：从 LocalStorage 获取（推荐）**
1. 登录 [platform.deepseek.com](https://platform.deepseek.com)。
2. 按 `F12` 打开开发者工具 → `Application`（应用） → `Local Storage`（本地存储）。
3. 找到 `userToken` 字段，复制其值填入插件配置。

**方法二：从 Cookie 获取（更直观）**
1. 按 `F12` 打开开发者工具 → 切换到 `Network`（网络）标签页。
2. 刷新页面，随便点开一个请求，在 `Headers`（标头）的 `Request Headers` 里找到 `Cookie`。
3. 在 Cookie 里找到 `userToken=xxxxxx`，复制等号后面的那串字符即可。（填入插件时，如果带了 `Bearer `，代码会自动清洗掉，放心填）。

## 🚀 使用方法

在群聊中发送：
- `/dsusage`：查询默认天数
- `/dsusage 7`：查询最近 7 天
- `/dsusage today`：查询今天
- `/dsusage month`：查询本月
- `/dsusage 10.01 10.31`：查询指定范围
- `/dsusage help`：查看帮助面板
